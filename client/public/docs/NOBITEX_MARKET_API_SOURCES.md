# منابع دادهٔ بازار نوبیتکس

منبع منتخب کاربر برای پنل بازار داخلی، نوبیتکس است. همهٔ قیمت‌های تتر/تومان باید با برچسب روشن «منبع: نوبیتکس» نمایش داده شوند؛ قیمت صرافی دیگر نباید جای نرخ نوبیتکس نشان داده شود.

| داده | endpoint رسمی | نکتهٔ قرارداد |
|---|---|---|
| آمار زندهٔ بازار | `GET https://apiv2.nobitex.ir/market/stats?srcCurrency=usdt&dstCurrency=rls` | عمومی، بدون توکن، سقف ۲۰ درخواست در دقیقه. `latest`، `bestBuy`، `bestSell`، `mark`، سقف/کف و حجم در پاسخ‌اند. واحد پاسخ ریال است و برای نمایش تومان باید بر ۱۰ تقسیم شود. |
| دادهٔ نمودار OHLC | `GET https://apiv2.nobitex.ir/market/udf/history?symbol=USDTIRT&resolution=<resolution>&to=<unix-seconds>&countback=<n>` | عمومی، بدون توکن، سقف ۶۰ درخواست در دقیقه. خروجی UDF شامل `t/o/h/l/c/v` است؛ قیمت‌های USDTIRT در دادهٔ رسمی نمودار به تومان دریافت می‌شوند. |

در اعتبارسنجی زندهٔ ۲۵ اوت ۲۰۲۶، endpoint آمار نوبیتکس پاسخ `status=ok` برای `usdt-rls` برگرداند و endpoint OHLC، ۲۴ کندل ساعتی واقعی را برگرداند. نرخ نهایی در بازارهای ایران بین صرافی‌ها ممکن است متفاوت باشد؛ پنل باید صرافی و زمان دریافت را کنار نرخ نمایش دهد.

منابع رسمی: [آمار بازار نوبیتکس](https://apidocs.nobitex.ir/market_data/%D8%A2%D9%85%D8%A7%D8%B1-%D8%A8%D8%A7%D8%B2%D8%A7%D8%B1) و [داده‌های OHLC نوبیتکس](https://apidocs.nobitex.ir/market_data/%D8%AF%D8%B1%DB%8C%D8%A7%D9%81%D8%AA-%D8%AF%D8%A7%D8%AF%D9%87-%D9%87%D8%A7%DB%8C-ohlc).

## دادهٔ لحظه‌ای

نوبیتکس در مستندات رسمی خود کانال‌های عمومی وب‌سوکت مبتنی بر Centrifugo را برای وضعیت بازار، معاملات، اردربوک و کندل معرفی می‌کند؛ کانال‌های عمومی به توکن نیاز ندارند. کانال آمار بازار با نماد uppercase مانند `BTCIRT` یا `ETHUSDT`، همان فیلدهای `bestSell`، `bestBuy`، `latest`، حجم و تغییر روزانه را منتشر می‌کند. کانال کندل نیز OHLC را تقریباً هر ۱۰ ثانیه به‌روزرسانی می‌کند. منابع رسمی: [وب‌سوکت نوبیتکس](https://apidocs.nobitex.ir/websocket/%D9%88%D8%A8-%D8%B3%D9%88%DA%A9%D8%AA) و [کانال وضعیت بازارها](https://apidocs.nobitex.ir/websocket/websocket-market-stats-channel).

رشتهٔ رسمی کانال وضعیت یک بازار `public:market-stats-{MARKET_SYMBOL}` و برای همهٔ بازارها `public:market-stats-all` است. endpoint اصلی اتصال `wss://ws.nobitex.ir/connection/websocket` است. این پروژه از یک اتصال عمومی و کانال همهٔ بازارها استفاده می‌کند و فقط دادهٔ دارایی‌های منتخب را به رابط اعمال می‌کند؛ اطلاعات هویتی یا معاملاتی کاربر ارسال نمی‌شود.

API رسمی OHLC با نمادهایی مانند `BTCIRT` یا `USDTIRT` و رزولوشن‌های دقیقه‌ای، ساعتی و روزانه، حداکثر ۵۰۰ کندل در هر فراخوانی برمی‌گرداند. بازه‌های فعلی رابط با `60`، `240` و `D` برای پوشش ۲۴ ساعت، ۷ روز و ۳۰ روز نگاشته شده‌اند. منبع: [دریافت داده‌های OHLC نوبیتکس](https://apidocs.nobitex.ir/market_data/%D8%AF%D8%B1%DB%8C%D8%A7%D9%81%D8%AA-%D8%AF%D8%A7%D8%AF%D9%87-%D9%87%D8%A7%DB%8C-ohlc).

## جست‌وجوی همهٔ بازارهای فعال

Endpoint عمومی `GET /market/stats?dstCurrency=rls` snapshot همهٔ بازارهای ریالی را بازمی‌گرداند؛ در بررسی زندهٔ ۲۵ اوت ۲۰۲۶، این snapshot شامل ۲۴۳ نماد بود. جست‌وجوی پروژه از همین snapshot استفاده می‌کند، نه فقط فهرست ارزهای اصلی. نتیجهٔ منطبق پیش از نمایش با endpoint OHLC همان نماد اعتبارسنجی می‌شود و فقط در صورت وجود حداقل دو کندل واقعی به رابط می‌رسد. برای کنترل فشار API، حداکثر ۱۰ تطابق اول هر عبارت جست‌وجو اعتبارسنجی می‌شوند؛ انتخاب هر نتیجه سپس ticker، bid/ask و نمودار همان بازار را تازه‌سازی می‌کند. مستندات رسمی دادهٔ بازار: [اطلاعات بازار نوبیتکس](https://apidocs.nobitex.ir/market_data/%D8%A7%D8%B7%D9%84%D8%A7%D8%B9%D8%A7%D8%AA-%D8%A8%D8%A7%D8%B2%D8%A7%D8%B1).

## منبع مکمل نرخ تومان، ارز و فلزات

در بررسی ۲۵ اوت ۲۰۲۶، صفحهٔ عمومی [Bonbast](https://www.bon-bast.com/) نرخ‌های دلار، یورو، پوند و ارزهای متعدد را با ستون‌های خرید/فروش به تومان، و همچنین طلا و نقره را نمایش می‌داد. صفحه صراحتاً واحد خود را تومان معرفی می‌کند و برای بسیاری از ارزها جدول عمومی دارد؛ بااین‌حال endpoint JSON عمومیِ بدون محدودیت از مستندات صفحه تأیید نشد و بعضی مسیرهای API پشت Cloudflare قرار دارند. بنابراین استفاده از Bonbast باید با parser محافظ، timeout، timestamp و برچسب stale انجام شود؛ هر مقدار نامعتبر یا قدیمی نباید به‌عنوان نرخ زنده نمایش داده شود. برای نرخ‌های لحظه‌ای‌تر و پوشش کامل‌تر، Navasan API در مستندات خود کلید لازم و سهمیهٔ رایگان محدود را اعلام می‌کند و تا زمان دریافت کلید نباید به‌عنوان منبع فعال پروژه فرض شود. منبع: [Bonbast](https://www.bon-bast.com/) و [Navasan API](https://www.navasan.tech/api/).
