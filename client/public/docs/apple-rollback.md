# سازوکار بازگشت «سیب»

نسخهٔ پایهٔ دقیق پیش از افزودن کنترل سنتر inline در checkpoint `97f2f0fb` ثبت شده است. این نسخه شامل همهٔ قابلیت‌های قبلی ربات و Mini App است و هیچ‌یک از منوهای inline جدید را شامل نمی‌شود.

اگر مالک پروژه عبارت «سیب را به حالت قبل برگردان» را اعلام کند، بازگشت باید به همین checkpoint انجام شود. این بازگشت فقط کد، تنظیمات پروژه و منوهای inline جدید را به وضعیت پایه برمی‌گرداند و نباید به‌صورت خودکار داده‌های پایگاه‌داده، رکوردهای تلگرام، تاریخچهٔ moderation یا تنظیمات بیرونی را حذف کند.

هر checkpoint بعدی که به‌عنوان نسخهٔ inline ذخیره شود باید شناسهٔ خود را جداگانه ثبت کند؛ تا زمانی که کاربر صریحاً «سیب» را اعلام نکرده است، نسخهٔ جدید نباید rollback شود.
