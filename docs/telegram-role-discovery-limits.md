# محدودیت‌های کشف نقش و اعضا در Telegram Bot API

این یادداشت، محدودهٔ عملی بخش اعضا و دسترسی نقش‌محور در Kronos Guard را مشخص می‌کند.

| نیاز | قابلیت مجاز Bot API | محدودهٔ عملی در Kronos Guard |
|---|---|---|
| تشخیص نقش یک کاربر مشخص | `getChatMember` | ربات می‌تواند وضعیت فعلی همان کاربر را در گروه، از جمله مالک، مدیر، عضو یا محدودشده بررسی کند؛ ربات باید در گروه مجوز لازم داشته باشد. |
| تشخیص مدیران گروه | `getChatAdministrators` | فهرست مالک و مدیران برای تازه‌سازی نقش‌های مدیریتی دریافت و در پنل نمایش داده می‌شود. |
| شمارش اعضا | `getChatMemberCount` | فقط تعداد کل اعضا نمایش داده می‌شود؛ این متد فهرست اعضا را برنمی‌گرداند. |
| فهرست همهٔ اعضا | در Bot API عمومی وجود ندارد | پنل فقط اعضای مشاهده‌شده در پیام‌ها، رویدادهای عضویت/خروج و مدیران دریافت‌شده از Telegram را فهرست می‌کند. ربات نباید ادعای اسکن کامل اعضا داشته باشد. |

Telegram Bot API روش عمومی برای دریافت فهرست کامل اعضای گروه ارائه نمی‌کند. بنابراین دکمهٔ «تازه‌سازی اعضا» در Kronos Guard فقط مدیران و تعداد اعضا را از Telegram به‌روز می‌کند، نقش کاربرِ واردشده به مینی‌اپ را مستقیماً بررسی می‌کند، و اطلاعات اعضای مشاهده‌شده را حفظ می‌کند.

منابع: [Bot API – Chat management](https://core.telegram.org/bots/api#getchatmember)، [Bot API – getChatAdministrators](https://core.telegram.org/bots/api#getchatadministrators)، [Bot API – getChatMemberCount](https://core.telegram.org/bots/api#getchatmembercount).
