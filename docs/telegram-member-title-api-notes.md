# یادداشت فنی: عنوان و تگ اعضای گروه در Telegram Bot API

تاریخ بررسی: ۱۹ اوت ۲۰۲۶.

مستندات رسمی فعلی Telegram Bot API روش `setChatMemberTag` را برای ثبت تگ یک عضو عادی در گروه یا سوپرگروه نشان می‌دهد. فرمان «تنظیم لقب» در Kronos Guard فقط همین مسیر را برای اعضای عادی به کار می‌گیرد؛ برای مدیران و مالک اصلی گروه هیچ عنوان یا تگ تلگرامی را تغییر نمی‌دهد. پاسخ موفقیت تنها پس از تأیید پاسخ Bot API ارسال می‌شود و هر محدودیت دسترسی یا خطای API بدون ادعای موفقیت بازتاب داده می‌شود.

منبع رسمی: <https://core.telegram.org/bots/api#setchatmembertag>
