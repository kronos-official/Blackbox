# یادداشت منبع نرخ ارز جهانی

منبع بررسی‌شده: [ExchangeRate.host supported currencies](https://exchangerate.host/currencies)

صفحه اعلام می‌کند API این سرویس ۱۶۸ ارز جهانی و فلزات گران‌بها را پوشش می‌دهد. در فهرست آن کدهای USD، EUR، GBP، CNY و IRR و همچنین XAU (طلا) و XAG (نقره) دیده می‌شود. این منبع برای فهرست نمادها و نرخ‌های تبدیل جهانی مناسب است، اما نرخ بازار آزاد ایران و تفاوت ریال/تومان باید جداگانه و با برچسب منبع/زمان داده مدیریت شود؛ نباید نرخ تومانی ساختگی یا بدون timestamp نمایش داده شود.

منبع جایگزین بررسی‌شده: [Frankfurter](https://frankfurter.dev/)

Frankfurter نرخ‌های مبتنی بر بانک مرکزی اروپا را ارائه می‌کند و برای ارزهای جهانی مناسب است، اما برای نیاز نرخ بازار ایران باید پوشش IRR و منبع تبدیل تومان جداگانه بررسی شود.
